NUSANTARA SKY HEROES 3D — PROTOTIPE BROWSER

Buka index.html di Chrome / Edge / Firefox.

TEKNOLOGI
- HTML + CSS + JavaScript Canvas.
- Visual dibuat pseudo-3D/2.5D: perspektif, scaling musuh saat mendekat, dan gerak maju.
  Pendekatan ini ringan untuk HP, laptop, dan papan interaktif dibanding WebGL 3D penuh.

ASET
- hero.png dan enemy.png berasal dari dua gambar yang dilampirkan pengguna.
- Gambar lampiran mengandung watermark PNGTree. Untuk distribusi/publikasi, gunakan aset
  yang memiliki lisensi/hak penggunaan yang sesuai atau ganti dengan aset orisinal.

FITUR
- Solo, Duo, Squad (shared-device P1-P4)
- Kelas 1–6 dan 10 mapel
- Mudah / Sedang / Sulit
- Drag/swipe/tap dan keyboard
- Nyawa: terkena tembakan mengurangi HP; HP 0 = MISI GAGAL
- Pause dan kembali ke menu
- Musuh bergerak, mendekat, menembak
- Skor, 10 tantangan per misi, reward 1–3 bintang
- Perjalanan Jawa, Bali, Kalimantan, Sulawesi, Maluku, Papua
- Musik menu, engine ambience, laser/tembakan, terkena, ledakan (sintetis/orisinal)

CATATAN PENDIDIKAN
Bank soal merupakan prototipe HOTS/kontekstual. Sebelum digunakan sebagai asesmen resmi,
guru perlu memvalidasi dan menyesuaikan CP/ATP, fase, materi, buku ajar, konteks sekolah,
dan kebijakan kurikulum yang sedang berlaku.
